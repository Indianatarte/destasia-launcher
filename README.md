# Destasia Launcher

Launcher officiel du serveur **Minecraft RP Destasia** (Minecraft Java Edition 1.12.2, Forge).

## Ce qu'il fait

- **Connexion avec ton compte Microsoft** : il faut posséder Minecraft Java Edition. Aucun mode hors ligne ou « crack ».
- **Installation automatique** de Minecraft 1.12.2, de Forge, de Java et de tous les mods du serveur.
- **Mises à jour automatiques** : quand les mods du serveur changent, le launcher les met à jour au lancement.
- **Un clic pour jouer** : il lance le jeu et se connecte directement au serveur.

## Installation

1. Télécharge l'installeur `Installer-Destasia.exe` (lien donné sur le serveur).
2. Lance-le et suis les étapes.
3. Ouvre **Destasia Launcher**, connecte-toi avec ton compte Microsoft, puis clique sur **Jouer**.

## Confidentialité

- La connexion passe directement par les serveurs de Microsoft et de Mojang.
- Les jetons de connexion restent sur ton ordinateur : rien n'est envoyé ni stocké ailleurs.
- Ce launcher est gratuit et réservé à la communauté Destasia.

## Contenu de ce dépôt

Le dossier `pack/` contient le pack de mods que le launcher télécharge (liste dans `pack/manifest.json`).
